# VSF Recommendation System

Kho ma nguon phuc vu nghien cuu, phan tich va xay dung he thong goi y san pham.

## Cau truc

- `docs/`: tai lieu va ghi chu du an.
- `notebooks/`: notebook phan tich du lieu va EDA.
- `src/vsf_recommendation_system/`: ma nguon cot loi.
- `sample_data/`: du lieu mau nho, an toan de chia se.
- `pyproject.toml`: metadata du an va dependencies Python.

## Cai dat

Yeu cau Python 3.11 tro len.

```bash
python -m pip install -e ".[eda]"
```

Chi dua du lieu mau nho, da loai bo thong tin nhay cam vao `sample_data/`. Khong commit tap du lieu raw lon.
